# Fútbol Total - Proyecto Final HTML5 (Coderhouse)

**Sitio web publicado:** https://noka11.github.io/Nu-ezMarrcosPre-entrega-html2/

## Descripción del Proyecto
Fútbol Total es un portal web dedicado al mundo del fútbol. Ofrece información sobre equipos icónicos, perfiles de jugadores destacados, tablas de estadísticas de la última temporada, integración multimedia y un formulario de contacto accesible.

## Estructura de Archivos
- `index.html`: Página principal e introducción al sitio.
- `pages/competiciones.html`: Información sobre torneos internacionales.
- `pages/equipos.html`: Perfiles de clubes y mapas de estadios.
- `pages/jugadores.html`: Biografías, estadísticas y videos destacados.
- `pages/contacto.html`: Formulario de interacción para usuarios.
- `assets/`: Carpeta con imágenes y recursos multimedia.

## Estándares y Calidad
- Estructura 100% HTML5 semántica.
- Cumplimiento de pautas de accesibilidad.
- Validación aprobada en W3C HTML Validator sin errores.
